# 네이버 블로그 원고 쓰기

## 먼저 할 일

1. `memo.txt`를 읽어요. 여기 적힌 것만 사실로 써요.
2. `ready/` 사진을 모두 직접 열어 보고, 사진마다 무엇이 보이는지 한 줄씩 메모해요.
3. 사진 순서를 정해요: 외관·입구 → 공간·분위기 → 주인공(메뉴·제품) → 디테일 → 마무리 컷.

## 말투

- 친구에게 추천하듯 다정한 존댓말("~했어요", "~더라고요"). 과장 광고 문구는 쓰지 않아요.
- 문단은 2~3문장. 한 줄이 너무 길면 줄을 나눠요. 모바일에서 읽기 편하게.
- 이모지는 문단 시작에 가끔만(글 전체에 3~5개).
- 메모에 없는 가격, 영업시간, 주차, 메뉴 이름은 쓰지 않아요. 필요하면 "방문 전에 확인해 보세요"라고 적어요.

## 구조

1. **제목**: `지역 + 가게/장소 이름 + 핵심 한 가지` (25자 안팎). 예) `성수 ○○카페, 창가 자리가 예쁜 브런치`
2. **첫 문단**: 왜 갔는지, 한 줄 결론.
3. **본문**: 사진 1장마다 1~2문단. 사진 바로 아래에 그 사진 이야기를 써요.
4. **정리**: 좋았던 점 / 아쉬웠던 점 / 이런 분께 추천 — 짧은 목록으로.
5. **장소 정보**: 메모에 가게 이름이 있으면 `place` 블록을 하나 넣어요.
6. **출처**: 직접 찍지 않은 사진이 있으면 맨 끝에 `사진 출처: …`.

## 검색에 잘 걸리게

- 제목과 첫 문단, 마지막 정리에 `지역 + 장소 이름`을 자연스럽게 한 번씩.
- 같은 단어를 억지로 반복하지 않아요.
- 태그 6~10개: 지역, 장소 이름, 업종, 메뉴, 상황(데이트·혼밥 등).

## 결과물

- `post.md`: 사람이 읽는 원고. 사진 자리는 `![](ready/01.jpg)`.
- `post.json`: `CLAUDE.md`의 형식대로. `post.md`와 내용이 똑같아야 해요.
- 다 쓰면 제목, 사진 수, 태그를 짧게 보여 주고, 확인이 필요한 사실(가격·메뉴명 등)을 따로 짚어 줘요.
