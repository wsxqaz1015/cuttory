# 컷토리 블로그 키트 · Claude Code 작업 규칙

이 폴더는 사진과 경험 메모로 네이버 블로그 글을 쓰고, 네이버 편집기에 임시저장하거나 예약해 주는 키트예요.
사용자는 개발자가 아니에요. 한국어로, 짧고 쉬운 말로 진행 상황을 알려 주세요.

## 폴더

- `config.json`: `blogId`(네이버 아이디), `chromePath`(비워 두면 설치된 Chrome을 자동으로 찾음)
- `posts/<글이름>/`: 사진·영상과 `memo.txt`. 작업 결과는 같은 폴더에 생겨요.
  - `ready/`: 얼굴을 가리고 정리한 사진 (원본은 그대로 둠)
  - `post.md`: 사람이 읽는 원고
  - `post.json`: 네이버 입력 스크립트가 읽는 원고
- `profiles/`: 네이버 로그인 정보가 든 Chrome 프로필. 절대 다른 곳에 올리거나 보내지 마세요.
- `logs/`: 실패할 때 남는 화면 캡처와 기록

## 글 하나 올리기 (이 순서를 지켜요)

1. **사진 정리**: `node scripts/prepare-photos.mjs posts/<글이름>`
   - HEIC는 JPG로 바꾸고(Mac), 사진 속 얼굴을 모자이크해서 `ready/`에 저장해요.
   - 끝나면 `ready/` 사진을 **직접 열어서** 모자이크가 빠진 얼굴이 없는지 확인하고, 빠진 게 있으면 사용자에게 알려요.
   - 영상 속 얼굴은 자동으로 가리지 않아요. 영상이 있으면 꼭 말해 주세요.
2. **원고 쓰기**: `.claude/skills/naver-blog-writer/SKILL.md`를 읽고 그대로 따라요.
   - 사진을 하나씩 직접 보고, `memo.txt`에 적힌 실제 경험만 바탕으로 써요. 메모에 없는 가격·영업시간·메뉴를 지어내지 마세요.
   - `post.md`와 `post.json`을 함께 만들어요. 형식은 아래에 있어요.
3. **네이버 입력**:
   - 임시저장: `node scripts/naver.mjs draft posts/<글이름>`
   - 예약: `node scripts/naver.mjs schedule posts/<글이름> --at "2026-11-03 19:30"`
   - 로그인이 필요하면 스크립트가 멈추고 Chrome을 열어 둬요. 사용자에게 "열린 Chrome에서 네이버에 로그인해 주세요"라고 알리고, 사용자가 다 했다고 하면 같은 명령을 다시 실행해요.
4. **결과 알리기**: 무엇을 넣었는지(사진 수, 지도, 태그), 확인할 점(가격·업체 정보·모자이크)을 짧게 알려요.

## 꼭 지킬 것

- `login`, `list`는 사용자가 Chrome에서 직접 할 일이 있어 최대 10분까지 기다려요. 명령 시간 제한을 10분(600000ms)으로 넉넉히 주거나 백그라운드로 실행하세요. `draft`, `schedule`도 사진이 많으면 몇 분 걸려요.

- 사용자가 "예약해줘"나 "발행해줘"라고 분명히 말하기 전에는 `draft`(임시저장)만 해요.
- 즉시 발행 기능은 없어요. 예약은 지금부터 15분 이후, 10분 단위 시각만 돼요. 안 맞으면 가까운 10분 단위로 올리고 바뀐 시각을 알려요.
- 한 계정에 하루 1~2개까지만 예약해요. 여러 개를 부탁받으면 날짜를 나눠 걸어요.
- 스크립트가 실패하면 **성공했다고 말하지 마세요.** `logs/`의 최신 캡처를 열어 어디서 막혔는지 보고 알려요.
- 네이버 편집기 화면이 바뀌어 버튼을 못 찾는 경우, 캡처를 보고 `scripts/naver.mjs` 맨 위 `SEL`(버튼 이름 목록)만 고쳐서 다시 시도해도 돼요. 고친 내용은 사용자에게 알려요.
- 직접 찍지 않은 사진은 `memo.txt`에 적힌 출처를 글 끝에 꼭 넣어요.

## post.json 형식

```json
{
  "title": "글 제목",
  "blocks": [
    { "type": "text", "text": "문단 하나. 줄바꿈은 \n 으로" },
    { "type": "image", "file": "ready/01.jpg" },
    { "type": "text", "text": "다음 문단" },
    { "type": "place", "query": "가게 이름 지역" }
  ],
  "tags": ["태그1", "태그2"]
}
```

- `image.file`은 글 폴더 기준 경로예요. 사진은 꼭 `ready/` 안의 것을 써요.
- `place`는 메모에 가게 이름이 있을 때만 한 번 넣어요. 지도를 못 넣어도 나머지는 계속 진행돼요.
- 태그는 10개 이하, `#` 없이 적어요.

## 그 밖의 요청

- "제목 다시 뽑아줘", "더 짧게", "말투 바꿔줘": `post.md`·`post.json`만 고치고, 다시 임시저장할지 물어봐요.
- "예약 목록 보여줘": `node scripts/naver.mjs list` 로 예약 글 관리 화면을 열어 줘요.
- "그 예약 취소해줘": 예약 취소는 자동으로 하지 않아요. `list`로 화면을 열어 주고, 취소할 글에서 삭제나 수정을 직접 누르도록 안내해요.
