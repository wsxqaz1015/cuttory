사진과 메모로 네이버 블로그 글 쓰기 · 설치부터 예약까지

2026년 10월 31일 업데이트

목차

    사진 폴더와 경험 메모 한 줄을 주면, Claude Code가 글을 쓰고 네이버 편집기에 사진·지도·태그까지 넣어 주는 키트예요. 처음엔 임시저장까지만 해 보고, 내용을 읽은 뒤 예약을 걸어 보세요.

    적어 두면 아래 요청문에 내 주소가 자동으로 들어가요. 이 주소는 내 브라우저에만 남아요.

    처음이라면 이 순서로 따라 하세요

    1. 설치 맡기기아래 설치 요청문을 Claude Code에 붙여 넣어요. Mac, Windows 모두 같은 키트예요.
    2. 사진과 메모 넣기설치가 끝나면 posts/my-shop 폴더에 사진을 넣고, memo.txt에 실제로 겪은 일을 적어요.
    3. 임시저장해 보기“사진이랑 메모로 글 써서 임시저장까지만 해줘”라고 보내요. 네이버 로그인은 열린 Chrome에서 직접 해요.
    4. 읽고 예약하기가게 정보·가격·사진을 확인하고 날짜와 시간을 정해 예약을 부탁해요. 마지막에 예약 목록에서 제목과 시간을 확인하면 끝이에요.
    Claude Code에서 쓰는 키트예요Claude 웹사이트에 ZIP을 올리는 방식과는 달라요. 압축을 푼 폴더를 Claude Code에서 열고 쓰면 돼요.
    컴퓨터는 언제 꺼도 되나요?네이버에 글을 입력하고 예약을 거는 몇 분 동안만 켜 두세요. 예약 목록에 들어간 뒤에는 꺼도 정해 둔 시각에 네이버가 알아서 공개해요.

    준비물

    • 컴퓨터Mac 또는 Windows 10/11
    • Claude CodeClaude Pro 이상 요금제
    • Google Chrome네이버 입력에 써요
    • Node.js 20+ · uv없으면 설치 요청 때 Claude Code가 깔아 줘요

    성수 골목 카페, 창가 자리가 예쁜 브런치 맛집

    주말 오전, 사람 많지 않은 곳에서 천천히 브런치를 먹고 싶어서 다녀왔어요. 한 줄로 말하면 창가 자리 하나로 다시 가고 싶은 곳이었어요.

    ☕ 들어서자마자 햇빛이 테이블까지 길게 들어오더라고요. 라떼는 고소한 편이라 우유 좋아하시는 분께 잘 맞을 것 같아요.

    성수 골목 카페 · 서울 성동구

    #성수카페 #성수브런치 #창가자리 #주말카페

    예시 화면이에요. 실제 결과는 넣은 사진과 메모에 따라 달라져요.

    1. 설치는 Claude Code에 맡기세요

    처음 한 번만 Claude Code를 설치하고 로그인해 주세요. 그다음 키트를 둘 폴더를 Claude Code에서 열고, 내 컴퓨터에 맞는 요청문을 붙여 넣으세요.

    텍스트
    내 Mac에 컷토리 블로그 키트를 설치하고 세팅해줘.
내 블로그 주소: https://blog.naver.com/내_아이디

1. 지금 작업 폴더에 ZIP을 내려받아 압축을 풀어줘. 이미 키트가 있으면 덮어쓰지 말고 먼저 물어봐줘.
2. SETUP.md와 CLAUDE.md를 읽고, Node.js 20 이상·uv·Google Chrome이 있는지 확인해줘. 없는 건 공식 방법으로 설치해줘.
3. 키트 폴더에서 npm install을 하고, config.json의 blogId를 위 주소의 아이디로 넣어줘.
4. node scripts/naver.mjs check 로 Chrome이 열리는지 확인해줘.

내 블로그 주소: https://blog.naver.com/내_아이디

1. 지금 작업 폴더에 ZIP을 내려받아 압축을 풀어줘. 이미 키트가 있으면 덮어쓰지 말고 먼저 물어봐줘.
2. SETUP.md와 CLAUDE.md를 읽고, Node.js 20 이상·uv·Google Chrome이 있는지 확인해줘. 없는 건 공식 방법(winget 등)으로 설치해줘.
3. 키트 폴더에서 npm.cmd install을 하고, config.json의 blogId를 위 주소의 아이디로 넣어줘. Chrome 경로도 찾을 수 있는지 봐줘.
4. node scripts/naver.mjs check 로 Chrome이 열리는지 확인해줘.
5. posts/my-shop 폴더와 memo.txt가 있는지 보고, 설치한 폴더 위치와 결과를 알려줘.
사진은 내가 넣을게. 아직 글을 쓰거나 예약하지 마.
오류가 나면 성공했다고 하지 말고 어느 단계에서 막혔는지 알려줘.
    Windows에서 알아 둘 것아이폰 HEIC 사진은 자동으로 바꾸지 못해요. 휴대폰에서 JPG로 보내거나 미리 바꿔서 넣어 주세요.

    처음 글을 쓸 때 전용 Chrome 창이 열려요. 네이버 로그인 화면이 나오면 직접 로그인한 뒤 Claude Code에 “로그인했어, 다시 해줘”라고 보내면 돼요.

    profiles 폴더는 보내지 마세요profiles/ 폴더에 네이버 로그인 정보가 남아요. 키트를 다른 사람과 나눌 땐 이 폴더를 빼 주세요.

    2. 글 하나 올리기

    1. 사진과 메모 넣기posts/my-shop/ 폴더에 사진·영상을 넣고, memo.txt에 한두 줄 적어요. 가격이나 메뉴처럼 꼭 들어가야 할 사실은 메모에 적어 주세요.
      memo.txt 예시
      성수동 골목 카페 브런치. 창가 자리 햇빛이 좋았고 라떼 6,000원. 주말 오전이라 한산했음
    2. 임시저장 부탁하기같은 키트 폴더를 Claude Code에서 열고 이렇게 보내요.
      텍스트
      posts/my-shop 사진이랑 메모로 네이버 블로그 글 써서 임시저장까지만 해줘.
키트 규칙대로 사진 정리 → 원고 쓰기 → 네이버 입력 순서로 해줘.
얼굴 모자이크 결과는 직접 열어서 빠진 데가 없는지 확인해줘.
로그인이 필요하면 내가 열린 Chrome에서 할게. 예약이나 발행은 하지 마.
    3. 읽고 고치기네이버 글쓰기 화면의 “저장” 옆 숫자를 누르면 임시저장한 글을 볼 수 있어요. 고칠 점은 Claude Code에 말하면 원고에 반영해요. 모자이크가 빠진 얼굴이 없는지도 꼭 봐 주세요.
    4. 예약 걸기다 괜찮으면 날짜와 시간을 정해 부탁해요.
      텍스트
      이 글을 11월 3일 저녁 7시 30분에 예약해줘. 태그도 넣고, 예약 목록에서 제목과 시간도 확인해줘.
    5. 끝예약 목록에 글이 들어간 걸 확인하면 컴퓨터를 꺼도 돼요.

    예약 목록 보여줘

    막힐 때

    예약 시간이 안 맞춰져요

    네이버 예약은 10분 단위이고, 지금부터 15분 이후여야 해요. 7시 35분처럼 말하면 키트가 7시 40분으로 올리고 알려 줘요.

    임시저장한 글에 태그가 없어요

    네이버 임시저장에는 태그가 남지 않아요. 예약할 때 키트가 다시 넣어 주고, 직접 발행한다면 발행 창에서 태그를 한 번 더 넣어 주세요.

    글을 여러 개 걸고 싶어요

    하루 1~2개씩 날짜를 나눠 걸어 주세요. 사람 속도로 입력하도록 만들었지만, 한 계정에서 한꺼번에 많이 올리는 건 피하는 게 좋아요.

    직접 찍지 않은 사진을 써도 되나요?

    memo.txt에 사진 출처를 적어 두면 글 끝에 출처를 넣어 줘요. 출처를 밝힐 수 없는 사진은 쓰지 않는 게 좋아요.

    입력하다가 멈췄어요

    네이버 화면이 바뀌어 버튼을 못 찾았을 수 있어요. logs/ 폴더에 그때 화면이 저장돼요. Claude Code에 “방금 왜 멈췄는지 logs 캡처 보고 고쳐줘”라고 보내 보세요.

    얼굴이 덜 가려졌어요

    자동 모자이크는 옆얼굴이나 작은 얼굴을 놓칠 수 있고, 영상 속 얼굴은 가리지 않아요. 그 사진은 빼거나 직접 가린 뒤 다시 넣어 주세요.
