# 컷토리 카드뉴스

글, 링크, 문서(PDF·Word·TXT), 영상을 넣으면 인스타그램 카드뉴스를 만들어 주는 웹앱이에요.

- `index.html`: 첫 주소. 오피스(`office.html`)로 보내고, 주소에 `?`나 `#`가 붙은 예전 카드뉴스 링크는 `cardnews.html`로 보내요
- `cardnews.html`, `config.js`, `fonts/`: 컷토리 카드뉴스 화면
- `reels.html`: 컷토리 릴스 (영상 자막·컷 편집)
- `video.html`: AI 영상 외주 비서. 의뢰 내용과 제품 사진으로 훅 3개, 장면별 AI 프롬프트, 캡컷 편집 순서, 캡션, 견적 메시지를 만들어요 (10 크레딧). 가격표와 의뢰는 브라우저에 저장돼요.
- `portfolio.html`: 포트폴리오 만들기. 회사용(`?mode=company`)과 프리랜서용(`?mode=free`)으로 나뉘고, 인스타 인사이트 CSV나 캡처(10 크레딧)로 성과 숫자를 불러와요. PDF로 저장할 수 있어요.
- `brand.css`: 모든 도구가 같이 쓰는 흰 바탕 · 검은 알약 버튼 · 도구 탭 스타일
- `poses.html`, `poses.js`: 캐릭터 포즈 만들기. 캐릭터 그림 한 장을 올리면 고른 포즈로 다시 그려 줘요. 포즈 목록은 `poses.js`에서 고쳐요. 포즈 묶음의 '이모티콘'과 그림체 '이모티콘 낙서체'로 메신저 이모티콘 느낌을 내고, 결과의 ✨에서 글자·움직임을 넣어 360×360 GIF로 받아요. 주소 뒤에 `?demo`를 붙이면 크레딧 없이 흐름만 보는 체험 모드로 열려요.
- `worker/`: OpenAI 키를 숨겨 두고 AI 기능과 크레딧을 맡는 서버 (Cloudflare Workers)

## 서버 올리기 (Cloudflare 대시보드, 코드 실행 없이)

1. [dash.cloudflare.com](https://dash.cloudflare.com)에 가입하고 로그인해요.
2. **Workers & Pages → Create → Create Worker**. 이름은 `cuttory-api`로 하고 **Deploy**를 눌러요.
3. **Edit code**를 눌러 원래 코드를 모두 지우고, `worker/worker.js` 내용을 붙여 넣은 뒤 **Deploy**를 눌러요.
4. **Storage & Databases → KV → Create**에서 이름 `cuttory`로 저장소를 만들어요.
5. 만든 Worker의 **Settings → Bindings → Add → KV namespace**에서 변수 이름 `KV`, 저장소 `cuttory`를 골라 저장해요.
6. **Settings → Variables and Secrets → Add**에서 아래 값을 넣어요.
   - `OPENAI_API_KEY` (종류: Secret): OpenAI API 키
   - `ADMIN_KEY` (종류: Secret): 관리자 페이지용 비밀번호. 아무도 모르는 긴 글자로 정해요.
   - `ALLOWED_ORIGIN` (종류: Text): 사이트 주소, 예) `https://아이디.github.io`
7. Worker 주소(예: `https://cuttory-api.아이디.workers.dev`)를 열어 `{"ok":true,"ai":true,"kv":true}`가 보이면 끝이에요.
8. `config.js`의 `window.CUTTORY_API`에 그 주소를 넣어요.

## 구글 로그인 · 계정별 저장 (`account.js`)

모든 페이지 머리글 오른쪽에 **로그인** 버튼이 생겨요. 구글로 로그인하면 오피스 기록, 카드뉴스, 포트폴리오, AI 영상 기획, 크레딧이 그 계정에 저장되고 어느 기기에서든 이어져요. 서버에 `GOOGLE_CLIENT_ID`가 없으면 버튼이 숨겨지고 지금처럼 이 브라우저에만 저장돼요.

1. [console.cloud.google.com](https://console.cloud.google.com)에서 프로젝트를 만들어요(무료, 카드 등록 없음).
2. **API 및 서비스 → OAuth 동의 화면**: 외부(External), 앱 이름 `컷토리`, 지원 이메일을 넣고 저장해요. 게시 상태는 **프로덕션으로 게시**를 눌러요(이메일·이름만 쓰므로 심사가 필요 없어요).
3. **사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**: 유형 **웹 애플리케이션**, **승인된 JavaScript 원본**에 `https://wsxqaz1015.github.io`를 넣고 만들어요. 리디렉션 URI는 비워 둬요.
4. 나온 **클라이언트 ID**(`….apps.googleusercontent.com`)를 Worker **Settings → Variables and Secrets**에 `GOOGLE_CLIENT_ID` (종류: Text)로 넣어요.
5. `worker/worker.js` 최신 내용을 Worker **Edit code**에 다시 붙여 넣고 **Deploy**해요.

- 저장은 KV에 `data:<사용자>:<office|portfolio|video|cardnews>`로 들어가요. 무료 KV는 하루 쓰기 1,000번이라, 내용이 바뀐 경우에만 1분에 한 번 넘지 않게 모아서 보내고 창을 닫을 때 한 번 더 보내요.
- 처음 로그인할 때 계정에 이미 저장된 내용이 있으면 그걸 가져오고, 이 기기의 원래 내용은 `<키>.before-login`으로 남겨 둬요. 계정이 비어 있으면 이 기기의 내용을 올려요.
- 로그인 전에 쓰던 크레딧은 처음 로그인할 때 그 계정으로 옮겨져요.

## 관리자

사이트 주소 뒤에 `?admin`을 붙여 열고 `ADMIN_KEY`를 넣으면, 내 계정 페이지에서 혜택 코드를 만들고 받은 피드백을 볼 수 있어요.

## 크레딧

새 사용자는 100 크레딧으로 시작해요. 사용량은 `worker/worker.js` 맨 위 `COST`에서 바꿀 수 있어요.

| 기능 | 크레딧 |
|---|---|
| AI 카드 생성 | 10 |
| 영상으로 카드 생성 | 15 |
| AI 그림 (배경·인물 표지) | 20 |
| 말소리 받아 적기 | 10 |
| 링크 읽기 | 3 |
| 번역 | 5 |
| 제목 다시 뽑기 | 2 |
| 문구 다듬기 | 1 |
| 캐릭터 포즈 1장 | 15 |
| 캐릭터 턴어라운드 | 20 |

계정은 브라우저마다 하나씩 만들어지고, 같은 네트워크에서 하루 3개까지만 새로 만들 수 있어요.

## 24시간 에이전시 · 팀장 결재 흐름

- 팀원은 퇴근하지 않아요. 카페, 라운지, 폰부스, 창가, 동료 자리로 알아서 돌아다녀요.
- 창밖 하늘은 서울(한국 시간)의 태양 고도를 계산해서 해 뜨고 지는 과정, 노을, 별과 달을 보여 줘요. 어두워지면 조명이 켜져요.
- 사용자는 **대표**예요. 대표 옆자리의 **팀장(가온)**이 대표 대신 시안을 먼저 검토해요.
- `office/make-report.mjs`가 매일 아침(8:20) 리포트와 제작팀 콘텐츠 시안(카드뉴스·블로그·릴스, `office/drafts/날짜.json`)을 만들어요.
  - 데일리 담당 모아가 매일 `office/hot/<날짜>.json`에 오늘의 핫이슈를 남겨요. 네이버 뉴스(뉴스홈 헤드라인, 많이 본, 댓글 많은), 구글 뉴스 주요 기사, 마케팅 매체 새 기사를 모아 여러 곳에 겹친 기사일수록 점수를 높이고, AI가 카드뉴스로 쓸만한 5개를 이유·각도와 함께 골라요. 출처별 건수(출처 현황)도 같이 남겨요. 편 갈리는 정치 공방, 참사·범죄 피해 기사는 빼요.
  - 카드뉴스 담당 다온은 모아가 넘긴 1위 이슈(기사를 못 읽으면 다음 순위)의 기사 본문으로 써요. 실패하면 데일리 카드로 대신해요. 데일리 리포트 창의 '🔥 오늘의 핫이슈'와 시안 창의 '🤝 협업 기록'에서 누가 무엇을 넘겼는지 볼 수 있어요.
  - 하루 작업에 AI 호출이 40번 넘게 들어가요. 저장소 Secrets에 `OPENAI_API_KEY`를 넣어 두면 크레딧 대신 그 키로 돌아가요.
  - 릴스는 **콘텐츠 전략 비서**가 고른 주제(`office/content-secretary/날짜.json`)에서 승인한 것 → TOP 순 → 점수 순으로 아직 안 쓴 주제를 골라, @lucky_marketer 말투로 1분 안쪽 대본(썸네일·컷별 자막·엔딩·캡션·직접 채울 것)을 써요. 비서 주제가 없으면 데일리 카드로 대신해요.
  - 블로그는 그날 데일리 리포트 카드로 써요.
  - 한 종류만 다시: Actions에서 kind `drafts`, id 날짜, only `reels`처럼 실행해요.
  - 팀원 AI가 시안을 쓰면 팀장 AI가 100점 기준으로 채점하고 수정 지시를 줘요.
  - 80점을 넘거나 시안이 5번이 될 때까지 고쳐요. 검토 기록은 각 json의 `review`(리포트) 또는 `rounds`(시안)에 남아요.
- 오피스에서는 팀원이 시안을 들고 팀장에게 가서 검토받는 장면이 나오고, 통과한 것만 팀장이 대표 자리로 가져와요.
- 🗂 결재함에서 대표가 승인하거나, 수정 지시(브라우저에서 AI 10크레딧)를 하거나, 반려해요. 시안은 대표 지시를 포함해 최대 5번까지예요.

## 업무 오피스 (`office.html`)

매일 아침 트렌드팀이 마케팅 리포트를 들고 출근하고, 제작팀이 카드뉴스·블로그·릴스·이모티콘·콘텐츠 비서·프리랜서 비서 도구를 하나씩 맡는 픽셀 사무실이에요. 제작팀 도구 주소는 `office.html`의 `PROD`에서 바꿔요. 오피스가 회사(에이전시) 본사이고 컷토리 도구들은 그 안의 팀이 쓰는 도구예요. 1F 스튜디오는 창가 집중석(트렌드팀), 체크 러그 위 회의 테이블(나·포트폴리오 매니저), 긴 원목 테이블(제작팀), 폰부스, 카페 바, 라운지로 나뉘고, 자리는 `SEATS`, 층 목록은 `FLOORS`에서 바꿔요. 회사 이름은 ⚙️ 설정에서 정해요. 리포트를 읽고 퀴즈를 풀고 스크랩하면 경험치가 쌓여 인턴에서 CMO까지 승진하고, 직급마다 사무실 가구가 늘어나요.

- `office.html`: 화면 전체 (기록은 브라우저 localStorage에 저장)
- `office/make-report.mjs`: 마케팅 뉴스(언론사 RSS·구글 뉴스)를 모아 AI로 리포트를 쓰는 스크립트
- `office/reports/<종류>/<날짜>.json`: 리포트 원본, `office/reports-data.js`: 화면이 읽는 묶음 파일
- `.github/workflows/office.yml`: 매일 아침 8:20(한국 시간)에 리포트를 써서 저장소에 올려요. 월요일엔 위클리, 1일엔 먼슬리, 분기 첫날엔 분기 리포트도 같이 써요.
- 저장소 **Settings → Secrets and variables → Actions**에 `OPENAI_API_KEY`를 넣으면 컷토리 서버 대신 OpenAI를 바로 불러 더 좋은 모델(기본 `gpt-5.4-mini`, 변수 `OFFICE_MODEL`로 변경)로 써요. 없으면 컷토리 서버의 `/api/ai`를 써요.
- 리포트를 다시 쓰려면 Actions → 트렌드 오피스 리포트 → Run workflow에서 종류·날짜와 `yes`를 넣어요.
- 리더보드는 서버의 `/api/office/board`, `/api/office/score`를 써요. `worker/worker.js`를 다시 붙여 넣고 Deploy해야 켜져요. 그 전에는 내 기록만 보여요.
- 주소 뒤에 `?at=2026-11-02T09:05`를 붙이면 그 시각의 사무실을 미리 볼 수 있어요 (기록은 남지 않아요).
